スパイスと乳香 ─ 天然香料のみの処方

柑橘を一切使わないスパイス／樹脂／白檀の構造　配合比は10%希釈液どうしの比率・合計100

この香りが成立する最小本数。1本でも抜くとこの香りでなくなる限界点を示す、学習と分析のための処方です。

µL
3役の読み方
  • 看板 … その香りと聞いて誰もが思い浮かべる匂い。この香りは「スパイス」と「インセンス」の2枚看板です。
  • 相棒 … 看板だけでは単調なので、明るさ・苦み・甘みのいずれかで対比をつくる役。
  • 固定剤 … 揮発を遅らせ、奥行きと持続を与えて立体にする役。
実習の進め方
  • 5本すべてを仕込んだものと、1本ずつ抜いた5本を並べて比較すると、各素材の仕事がはっきり分かります。
  • スケルトンからベースアコードへの差分が、そのまま「肉付けの手順」になります。

スケルトンに肉付けし、それ自体を1つの素材として使えるようにした常備アコード。完成品の20〜40%を占める部品として使います。

µL
スケルトンからの差分＝肉付けの手順
  • シダーウッドを足す → 白檀だけでは丸すぎた底に、乾いた輪郭が入る。
  • ベンゾインを足す → ラブダナムだけでは動物的すぎた甘さが、樹脂の丸い蜜になる。
  • ローズを足す → スパイスの塊に花の芯が通り、蜜っぽさが一段増す。
  • ブラックペッパー・コリアンダーを足す → カルダモンとクローブの間が埋まり、スパイスが1つの塊に聞こえる。
  • ナツメグを足す → 厚みが出て、スパイスが平面から立体になる。
使い方
  • このアコードを1素材として35前後で使い、ゼラニウム・シナモンリーフ・スティラックスを足すと、フル処方に近い形に組み上がります。
  • 原作は名前こそオードパルファムですが実質はパルファム濃度です。賦香率15〜20%まで上げても成立します。

公表ノート16項目すべてに担当を割り当てた完成形の処方です。

µL
仕込みの手順
  • ベース → ミドル → トップ の順に入れ、キャップを閉じて指で弾き混ぜ、最低10分置いてからムエットへ。
  • 直後・10分後・1時間後・翌日の4回、印象を記録する。
安全・取り扱い
  • この処方はIFRAの制限が実際に効く唯一の処方です。クローブバッド4＋シナモンリーフ2で、オイゲノールは処方全体の約0.48%。賦香率10%なら最終製品で約0.048%となり、制限内に収まります。この2本を増やすと超えます。
  • クローブとシナモンの合計6を動かさないでください。スパイスを強くしたい場合は、カルダモン・ブラックペッパー・ナツメグの側で増やします。
  • シナモンは必ず葉（リーフ）を使います。樹皮はシンナムアルデヒドによる皮膚感作性が強く、肌用には向きません。
  • ナツメグはミリスチシンを含みます。この配合比を超えて増やさないでください。
  • ラブダナム・ベンゾイン・スティラックスは粘度が高く、10%希釈時に湯せんまたは一晩静置が必要です。

この香りは公表ノートのほぼ全部が天然でそのまま揃う、珍しい例です。置き換えが必要なのはハニーだけで、代わりに安全上の制限が実際に効いてきます。

さらに素材が欠ける場合
  • スティラックス → ベンゾインを3増やす。バルサム感は残りますが、わずかな煙は消えます。
  • ローズAbs → ローズオットーで代用可。蜜っぽさが減るので、ベンゾインを1増やすと釣り合います。
  • フランキンセンス → 代替は存在しません。この香りの看板なので、これだけは揃えてください。
  • シナモンリーフ → 無ければ省く。クローブが同じオイゲノール系なので、方向は保たれます。
  • サンダルウッド → アミリス（ウエストインディアン・サンダルウッド）で代用可。乳っぽさは減ります。
確認の順番
  • まずスケルトン5本を仕込み、狙った香りになっているかを確認する。
  • 次にスパイスアコード（カルダモン・クローブ・ナツメグ・ブラックペッパー・シナモンリーフ）だけを仕込み、1本1本が聞き分けられず「スパイスの塊」に溶けているかを確認する。バラバラに聞こえるうちは配合が合っていません。
  • さらにハニーアコード（ベンゾイン・ラブダナム・ローズ）を単独で仕込み、蜜に読めるかを確認する。
  • この3つが合格してからベースアコード、フル処方の順に組むと失敗が減ります。

この処方は、下記の市販香水の公表ノートを手がかりに構成した独自の処方です。配合比はすべて推定であり、実際の処方ではありません。商標は各権利者に帰属し、nehneとは関係ありません。
