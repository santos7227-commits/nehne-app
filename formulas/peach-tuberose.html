ピーチとチュベローズ ─ 天然香料のみの処方

フルーティ／ホワイトフローラル／スイートウッディの三層構造　配合比は10%希釈液どうしの比率・合計100

この香りが成立する最小本数。1本でも抜くとこの香りでなくなる限界点を示す、学習と分析のための処方です。

µL
3役の読み方
  • 看板 … その香りと聞いて誰もが思い浮かべる匂い。この香りは「ピーチ」と「白い花」の2枚看板です。
  • 相棒 … 看板だけでは単調なので、明るさ・苦み・甘みのいずれかで対比をつくる役。
  • 固定剤 … 揮発を遅らせ、奥行きと持続を与えて立体にする役。
実習の進め方
  • 5本すべてを仕込んだものと、1本ずつ抜いた5本を並べて比較すると、各素材の仕事がはっきり分かります。
  • スケルトンからベースアコードへの差分が、そのまま「肉付けの手順」になります。

スケルトンに肉付けし、それ自体を1つの素材として使えるようにした常備アコード。完成品の20〜40%を占める部品として使います。

µL
スケルトンからの差分＝肉付けの手順
  • ジャスミンサンバック・オレンジフラワーを足す → イランイラン一本では出せない、チュベローズ特有の濃く青い甘さになる。
  • ベンゾインを足す → オスマンサスのアプリコット感に産毛の乳っぽさが乗り、はじめて「桃」になる。
  • ローズを足す → 花束の芯が通り、白い花がばらけなくなる。
  • オレンジフラワーを厚くする → 蜂蜜様の甘さが差し、スイカズラの側に寄る。
  • シダー・ベチバーを足す → 甘さ一辺倒だった底に乾いた輪郭が出る。
使い方
  • このアコードを1素材として35前後で使い、ネロリ・コリアンダー・ローマンカモミール・オリス・ゼラニウム・バイオレットリーフ・アンブレットを足すと、フル処方に近い形に組み上がります。
  • アブソリュートの比率が高い処方なので、10%希釈液の時点で粘度が出ます。仕込む前に室温に戻しておくと吸い上げが安定します。

公表ノート16項目すべてに担当を割り当てた完成形の処方です。

µL
仕込みの手順
  • ベース → ミドル → トップ の順に入れ、キャップを閉じて指で弾き混ぜ、最低10分置いてからムエットへ。
  • 直後・10分後・1時間後・翌日の4回、印象を記録する。
安全・取り扱い
  • ローマンカモミールは1%希釈まで落とすと計量が安定します。
  • イランイランとジャスミンには感作性の報告があります。肌につける前提なら賦香率を10%以下に抑えてください。
  • 柑橘は肌につける前提ならFCF品を選ぶか、賦香率を下げてください。
  • オスマンサス・ベンゾイン・バニラ・オリスは粘度が高く、10%希釈時に湯せんまたは一晩静置が必要です。
  • オリスコンクリートは非常に高価です。手持ちが無ければ省いても骨格は崩れませんが、パウダリーな余韻は出ません。

公表ノートの果実と花の多くは天然の精油が存在しません。1本で代わりになる素材が無いため、複数本のアコードに置き換えています。

さらに素材が欠ける場合
  • ジャスミンサンバックAbs → ジャスミングランディフローラムAbsで代用可（より濃く、やや獣っぽくなる）。
  • オレンジフラワーAbs → ネロリを4増やす（軽くなるが方向は同じ）。
  • ローズAbs → ローズオットーで代用可。量は3に落とすとバランスが取れます。
  • 蜜っぽさをもっと出したい場合 → ビーワックスAbsを2足し、ネロリとオレンジフラワーを1ずつ減らす。
  • オリスコンクリート → 代替は存在しません。省くか、手に入るまで待つかの二択です。
確認の順番
  • まずスケルトン5本を仕込み、狙った香りになっているかを確認する。
  • 次に桃アコード（オスマンサス・ベンゾイン・ローマンカモミール）だけを仕込み、桃に読めるかを確認する。
  • さらに白い花アコード（イランイラン・ジャスミンサンバック・オレンジフラワー）を単独で仕込み、チュベローズに寄っているかを確認する。
  • この3つが合格してからベースアコード、フル処方の順に組むと失敗が減ります。

この処方は、下記の市販香水の公表ノートを手がかりに構成した独自の処方です。配合比はすべて推定であり、実際の処方ではありません。商標は各権利者に帰属し、nehneとは関係ありません。
