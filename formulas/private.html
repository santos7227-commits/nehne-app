非公開処方

この画面の処方データは、お使いの端末の中だけに保存されます。サーバーにも GitHub にも送信されません。

ホーム画面に置く

nehne調香ノートとは別のアイコンになります。名前は「調香メモ」。中身が分からない名前なので、人に画面を見られても安心です。

ボタンが効かない場合は、Chromeの右上（または右下）の点3つ → 「ホーム画面に追加」または「アプリをインストール」を選んでください。同じアイコンが置かれます。

処方を追加する

複数まとめて選べます。同じIDの処方は上書きされます。

バックアップ

端末を変えるとき・アプリのデータが消えたときのために、書き出したファイルをクラウドに置いておいてください。

使い方とデータの形

この画面の仕組み

このページ自体は「表示器」で、処方の数値は入っていません。読み込んだJSONは端末のブラウザ保存領域（localStorage）に置かれ、次回からは一覧に並びます。

公開しているのは表示の仕組みだけなので、このページがGitHubにあっても、香料名や配合比が外から見えることはありません。

ブラウザの履歴やサイトデータを消すと保存も消えます。書き出したJSONは別に保管してください。

JSONの書き方

1つの処方が1ファイルです。tiers に段を並べます。段は3つでなくても構いません。

{
  "id": "sample",
  "name": "作品名",
  "subtitle": "天然香料のみの処方",
  "poem": "詩\n改行は \\n",
  "note": "香りの骨格の説明",
  "tiers": [
    { "key": "skeleton", "name": "スケルトン",
      "batch": 100, "desc": "この段の説明",
      "items": [
        { "n": "ベルガモット", "p": "トップ", "v": 31, "m": "メモ" }
      ] }
  ],
  "memo": ["注意書き1", "注意書き2"]
}

v は配合比（10%希釈液どうしの比率・合計100）。p は トップ／ミドル／ベース。batch はその段の既定の仕込み量（µL）です。
