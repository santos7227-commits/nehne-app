ラベンダーと苔 ─ 天然香料のみの処方

アロマティック・ウッディ。ラベンダー／木／苔の構造　配合比は10%希釈液どうしの比率・合計100

この香りが成立する最小本数。1本でも抜くとこの香りでなくなる限界点を示す、学習と分析のための処方です。

µL
3役の読み方
  • 看板 … その香りと聞いて誰もが思い浮かべる匂い。この香りは「ラベンダー」と「ミントの冷たさ」の2枚看板です。
  • 相棒 … 看板だけでは単調なので、明るさ・苦み・甘みのいずれかで対比をつくる役。
  • 固定剤 … 揮発を遅らせ、奥行きと持続を与えて立体にする役。
実習の進め方
  • 5本すべてを仕込んだものと、1本ずつ抜いた5本を並べて比較すると、各素材の仕事がはっきり分かります。
  • スケルトンからベースアコードへの差分が、そのまま「肉付けの手順」になります。

スケルトンに肉付けし、それ自体を1つの素材として使えるようにした常備アコード。完成品の20〜40%を占める部品として使います。

µL
スケルトンからの差分＝肉付けの手順
  • ホーウッドを足す → ラベンダーと白檀の間が埋まり、香りが一本の線につながる。ここが空いていると上下が分離して聞こえる。
  • オークモスを足す → 土くさいだけだったパチュリに、湿った苔の深さが出る。
  • ラブダナムを足す → 冷たい香りに体温が入り、着られる香りになる。
  • コリアンダーを足す → ラベンダーの薬っぽさが和らぎ、丸くなる。
使い方
  • このアコードを1素材として35前後で使い、キャラウェイ・スターアニスを足すと、ほぼフル処方になります。差が2本しかないのは、公表ノートが11項目しかないためです。
  • 原作はオードトワレです。賦香率は8〜12%が近くなります。

公表ノート16項目すべてに担当を割り当てた完成形の処方です。

µL
仕込みの手順
  • ベース → ミドル → トップ の順に入れ、キャップを閉じて指で弾き混ぜ、最低10分置いてからムエットへ。
  • 直後・10分後・1時間後・翌日の4回、印象を記録する。
安全・取り扱い
  • オークモスAbsはアトラノール／クロロアトラノールにIFRAの制限があります。配合比5なら処方全体の0.5%、賦香率10%で最終製品0.05%となり制限内です。低アトラノール品を選んでください。
  • スターアニスとキャラウェイの合計8を超えないでください。アネトールが増えると薬っぽさが前に出ます。
  • ペパーミントはメントールを含みます。増やすと歯磨き粉の方向に倒れるので、5で止めてください。
  • ラブダナムとオークモスは粘度が高く、10%希釈時に湯せんまたは一晩静置が必要です。

公表ノートのほぼ全部が天然でそのまま揃います。置き換えが必要なのは1本だけですが、それは入手性ではなく資源保護を理由とする置き換えです。

さらに素材が欠ける場合
  • ホーウッド → ローズウッドは使わないでください。同じリナロール系ならボアドローズ・ブラジル産の合法流通品もありますが、証明書のないものは避けます。
  • オークモスAbs → 省く場合はパチュリを3増やす。湿った深さは減り、乾いた土だけが残ります。
  • マンダリン → ベルガモット(FCF)で代用可。やや苦く、フゼアらしさは増します。
  • サンダルウッド → アミリスで代用可。乳っぽさは減ります。
  • キャラウェイ → クミンは避けてください。方向が近く見えて、汗の匂いに倒れます。
確認の順番
  • まずスケルトン5本を仕込み、狙った香りになっているかを確認する。
  • 次に冷たさアコード（ラベンダー・ペパーミント・マンダリン）だけを仕込み、清涼感が薬っぽさに倒れていないかを確認する。ここが決まればこの香りはほぼ決まります。
  • さらに土台（サンダルウッド・パチュリ・オークモス）を単独で仕込み、苔の湿り気が出ているかを確認する。
  • この3つが合格してからベースアコード、フル処方の順に組むと失敗が減ります。

この処方は、下記の市販香水の公表ノートを手がかりに構成した独自の処方です。配合比はすべて推定であり、実際の処方ではありません。商標は各権利者に帰属し、nehneとは関係ありません。
